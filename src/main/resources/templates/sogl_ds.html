Согласие на трансграничную передачу

Я, субъект персональных данных, свободно, своей волей и в своем интересе даю отдельное согласие на трансграничную передачу моих персональных данных (далее – ПДн) на территорию иностранного государства, не обеспечивающего адекватную защиту прав субъектов персональных данных (в соответствии с перечнем, утвержденным Роскомнадзором), на следующих условиях:

Условие

Передача в сервис DeepSeek

Получатель

DeepSeek (API api.deepseek.com), оператор – DeepSeek (Китайская Народная Республика)

Страна передачи

Китайская Народная Республика

Цель передачи

Обработка запросов пользователя с использованием искусственного интеллекта для генерации ответов, включая:

  • анализ текста запроса (промпта);
  • чтение оглавления проекта и сегментов текстовых файлов, указанных пользователем;
  • формирование релевантного ответа на основе переданных данных.
Передаваемые данные
  • Содержимое запроса (текст промпта);
  • Оглавление проекта;
  • Сегменты и текстовые файлы, которые пользователь явно включил в обработку (через интерфейс Сервиса);
  • Иные данные, добровольно внесенные пользователем в запрос или загруженные файлы.

Оператор не передает учетные данные (адрес электронной почты, пароль, JWT-токен, IP-адрес, userId) и любую иную информацию, собранную при регистрации или в рамках использования Сервиса, если она не является частью запроса.

Сведения об уровне защиты

Китайская Народная Республика не входит в перечень иностранных государств, обеспечивающих адекватную защиту прав субъектов персональных данных, утвержденный Роскомнадзором.

Дополнительные гарантии
  • Данные передаются только на время обработки запроса;
  • Оператор (ИП Трофименко А.А.) не хранит переданные данные после получения ответа от DeepSeek (за исключением логов факта передачи, хранящихся 6 месяцев в соответствии с Политикой обработки персональных данных);
  • DeepSeek обрабатывает данные исключительно для выполнения запроса и не использует их для обучения моделей (при условии использования платного API – данный факт подтвержден политикой DeepSeek).
Срок действия и отзыв

Согласие действует до момента отзыва. Отзыв может быть направлен по электронной почте [(${contactEmail})] с пометкой «Отзыв согласия на трансграничную передачу DeepSeek». В случае отзыва дальнейшая передача данных в DeepSeek прекращается, однако функция AI-ассистента на базе DeepSeek становится недоступной. Ранее переданные данные (до момента отзыва) не затрагиваются и обрабатываются DeepSeek в соответствии с его политикой.

Выражение согласия

Настоящее согласие дается путем проставления отдельной отметки (чекбокса) в модальном окне перед первым использованием функции DeepSeek. Чекбокс не активирован по умолчанию. Без его активации отправка запроса в DeepSeek технически невозможна.
